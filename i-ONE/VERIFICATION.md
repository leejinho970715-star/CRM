# i-ONE 수정 검수 기록

2026-10-12. 기존 CRM이 아닌 제품 랜딩 `/i-ONE/`만 수정했습니다.

- 큰 제목, 원형 화살표 CTA, 제품 로고가 포함된 표면형 탭, 갤러리 내부의 기능 탭으로 시각 위계를 바꿨습니다. 화이트·블루 `#1471EF`·시안 `#00AAF0`과 Pretendard를 유지했습니다.
- PC 1440×900에서 6개 제품·18개 기능을 전환했습니다. 지연 로딩 완료 후 18개 원본 이미지 모두 정상 로드를 확인했습니다. 이미지가 프레임 안에 있고 `object-fit: contain`으로 표시되며 가로 넘침이 없습니다.
- PC 1366×768, 태블릿 768×1024, 모바일 390×844·360×740·320×740에서 갤러리 높이가 헤더·제품 탭을 뺀 화면 높이와 일치합니다. 설명 잘림·문서 가로 넘침이 없고 하단 안내·다음 제품 버튼도 섹션 안에 있습니다. 모바일 실제 좌표 클릭 후에도 갤러리의 스크롤 위치가 유지됩니다.
- Amaranth10 일정관리와 자동전표처리는 제조사 서비스 페이지의 원본 PNG로 교체했습니다. 각각 4137×2903, 3918×2882px입니다. 화면 구성 일부가 원본에서 잘린 전자결재 홈페이지 이미지는 사용하지 않고, 전체 구성의 제안서 내장 이미지를 유지했습니다.
- 확대 창에서 ‘전체 보기’ → ‘원본 100%’ → 축소 → 전체 보기, Escape 닫기와 원래 버튼으로 포커스 복귀를 확인했습니다. 원본 100%에서는 4137×2903px로 표시되며 가로·세로 이동이 가능합니다. 이미지 크기를 원본 이상으로 늘리지 않습니다.
- GSAP은 CSS sticky 위에서 비주얼과 설명만 제어합니다. 소개 → 갤러리 → 역스크롤에서 소개가 다시 나타나며 `.pin-spacer`는 0개입니다. 제품 전환 후 추가 고정 여백도 없습니다.
- 제품 탭 방향키 이동, 모바일 메뉴 열기와 링크 선택 후 닫기, 기존 AX/DX 체크리스트 링크를 확인했습니다. 별도 설문은 구현하지 않았습니다.
- JavaScript 구문 검사, HTML 로컬 파일 존재 확인, 18개 원본 이미지 메타데이터, OG 1200×630px와 canonical 경로를 검증했습니다. 브라우저 콘솔 오류는 없습니다. OG를 새 CTA와 밝은 배경에 맞게 갱신했습니다.

모션 줄이기와 GSAP 미지원 대안은 코드 분기로 확인했습니다. OS 설정을 변경한 실증 테스트는 하지 않았습니다. 공개 자료의 압축·합성 품질에는 한계가 있으므로, 픽셀 수가 큰 파일로 바꿨다고 모든 글자가 새 4K 캡처 수준으로 복원됐다고 주장하지 않습니다. 실제 UI의 글자를 AI로 재작성하거나 가짜 세부 정보를 추가하지 않았습니다.

기존 `/products/` 링크는 검색 조건과 해시를 유지해 `/i-ONE/`으로 이동합니다. 배포 상태는 커밋 후 확인합니다.
