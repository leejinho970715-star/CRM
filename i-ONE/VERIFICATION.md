# i-ONE 수정 검수 기록

2026-10-12. 기존 CRM이 아닌 제품 랜딩 `/i-ONE/` 범위를 수정했습니다.

- GSAP pin을 제거하고 CSS sticky + 원래 위치의 소개 래퍼로 바꿨습니다. PC·모바일 정방향/역방향 스크롤에서 실제 소개 화면을 확인했으며 `.pin-spacer`가 생성되지 않습니다. 탭 전환 후에도 추가 고정 여백은 없습니다.
- PC 1440×900에서 6개 제품·18개 기능 탭을 전환해 이미지 로드, `object-fit: contain`, 프레임 내부 위치와 가로 넘침 없음 확인.
- PC 1024×768, 태블릿 820×1180, 모바일 390×844·320×740 확인. 소개 이미지 섹션 높이는 헤더·제품 탭을 뺀 화면 높이와 일치하고, 하단 안내·다음 제품 버튼도 섹션 안에 있습니다. 모바일에서 실제 좌표 클릭으로 기능 전환 후 갤러리 위치가 유지되는 것을 확인했습니다.
- Amaranth10 일정·회계·전자결재 이미지를 공개 제안서의 전체 예시 화면으로 교체. 원본 1038×669, 1042×671, 1314×861 픽셀을 유지합니다. 18개 화면 전체는 가로 1038–2400 픽셀입니다.
- 이미지 확대와 Escape 닫기·포커스 복귀, 탭 방향키와 모바일 메뉴를 확인했습니다.
- 블루 `#1471EF`·시안 `#00AAF0`과 중립 텍스트로 변경. SVG/PNG favicon, Apple 터치 아이콘과 OG 1200×630도 같은 색상으로 갱신했습니다.
- 기존 AX/DX 체크리스트 버튼의 목적지는 https://axdx-test.vercel.app/ 입니다. 별도 설문을 구현하거나 참고 사이트의 폼을 제출하지 않았습니다.
- JavaScript 구문 검사와 HTML 로컬 파일 존재 확인, 원본 이미지 메타데이터 검증. 브라우저 콘솔 오류 확인.

모션 줄이기와 GSAP 미지원 대안은 코드 분기로 확인했습니다. OS 설정을 변경한 실증 테스트는 하지 않았습니다. UI 해상도는 공개 원본의 한계가 있어 원본 픽셀을 유지하고, AI로 글씨를 재작성하거나 가짜 세부 정보를 추가하지 않았습니다.

기존 `/products/` 링크는 검색 조건과 해시를 유지해 새 주소로 이동합니다. 배포 결과와 최종 URL은 커밋 후 확인합니다.
