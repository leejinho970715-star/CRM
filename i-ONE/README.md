# i-ONE · 아이원소프트뱅크 제품 랜딩

기존 CRM과 별도로 열리는 회사·제품 소개 원페이지입니다.

- 배포 경로: `/i-ONE/`
- 제품 바로가기: `/i-ONE/#omniesol`, `#amaranth10`, `#wehago`, `#oneai`, `#nonprofit`, `#ifrs18`
- 빌드: `python scripts/build-product-landing.py` (표준 라이브러리만 사용)
- 콘텐츠 수정: `i-ONE/data.json`
- 스타일·동작: `landing.css`, `landing.js`
- 장식 배경: `backgrounds.css`, `assets/hero-tech-background.webp`, `assets/product-tech-light.webp`
- 기존 `/products/` 주소는 검색 조건과 제품 해시를 유지하며 `/i-ONE/`으로 이동합니다.
- 프리뷰: 저장소 루트에서 `python -m http.server 8940` 실행 후 `/i-ONE/` 접속

## 구성

두 로고를 병렬 배치한 헤더 → 제공된 3D 이미지 중심의 메인 → 6개 제품 탭 → 제품 소개 스크롤 모션 → 제품별 3개 기능의 실제 UI → 기존 AX/DX 체크리스트 연결 → 회사 소개 → 도입 안내 → 공식 상담 링크.

GSAP ScrollTrigger는 비주얼 확대·안착·설명만 제어하고, 화면의 고정은 CSS sticky가 담당합니다. 별도의 pin spacer를 만들지 않아 역스크롤과 탭 전환 시 빈 고정 영역이 남지 않습니다. 모바일은 짧은 타임라인을 사용합니다. 모션 줄이기 설정이나 GSAP 미지원 환경에서는 추가 스크롤 구간 없이 설명을 표시합니다. 제품 소개 건너뛰기, 방향키 탭 전환, 이미지 확대와 Escape 닫기도 제공합니다.

Pretendard, 더존 공식 사이트의 블루 `#1471EF`·시안 `#00AAF0`, 중립 본문 `#24272C`을 사용합니다. 네이비 UI 색상을 제거했습니다. 제공된 PNG는 보존하고 실제 페이지에서는 투명 여백을 정리한 WebP를 사용합니다. 제품 화면은 원본 비율을 유지하며 한 화면 높이의 갤러리에서 전체 이미지를 담습니다.

큰 제목과 여백, 원형 화살표가 있는 둥근 CTA, 제품 로고가 포함된 표면형 탭으로 구성했습니다. 기능 탭은 갤러리 안의 작은 전환 메뉴로 묶고, 화면과 설명을 나란히 배치합니다. 모바일에서는 화면 아래에 설명을 붙입니다. 확대 창의 ‘전체 보기’는 전체 구성을, ‘원본 100%’는 작은 글씨를 확인하는 용도입니다. 확대된 이미지는 가로·세로 스크롤로 이동합니다.

체크리스트는 새로 제작하지 않고 사용자 지정 https://axdx-test.vercel.app/ 로 연결합니다. 설문과 응답 처리 기능은 이 랜딩에 포함하지 않습니다.

## 자료와 범위

실제 기능 화면 18개는 공개된 제품 소개 자료에서 가져왔습니다. 각 화면에 원문 링크를 제공하며, 정확한 출처는 [SOURCES.md](SOURCES.md)에 기록했습니다. IFRS18은 Amaranth10 재무제표관리 기능으로 설명합니다. 비영리 자료는 공개 제안서의 예시 화면입니다.

모든 모듈을 설명하는 제품 매뉴얼 대신 대표 기능을 소개하는 랜딩입니다. 더 많은 기능은 각 제품의 공식 소개 링크에서 확인할 수 있습니다. 온라인 상담은 기존 아이원 문의 페이지로 이동하며, 이 페이지에서는 사용자 정보를 수집하거나 전송하지 않습니다.

별도의 설치·빌드 설정이 없는 정적 페이지로 GitHub Pages와 Vercel에서 같은 경로를 사용할 수 있습니다. 기존 CRM 소스와 라우트는 수정하지 않았습니다.
