# 사이트의 용도와 목적

**기업 담당자가 아이원소프트뱅크와 더존 솔루션의 차이를 이해하고, 실제 기능 화면을 확인한 뒤 도입 상담으로 연결되는 제품 소개 랜딩.**

주요 방문자는 경영관리·회계·인사·IT 업무를 맡고 있거나 시스템 도입을 검토하는 기업 담당자입니다. 처음부터 특정 제품을 알고 있지 않아도 회사의 역할, 제품의 적합한 업무와 대표 기능을 한 페이지에서 살펴볼 수 있게 합니다.

## 방문자의 흐름

1. 첫 화면에서 회사가 제공하는 가치와 제품군을 파악합니다.
2. 6개 제품 탭에서 관심 제품을 선택합니다.
3. 3D 제품 소개와 대표 기능 화면으로 사용 맥락을 이해합니다.
4. 공식 원문 링크로 더 자세한 기능과 자료를 확인합니다.
5. 기존 AX/DX 체크리스트로 업무 완성도를 확인하거나 공식 도입 상담으로 이동합니다.

제품마다 가장 설명하기 좋은 실제 UI 3개를 선별했습니다. 전체 모듈을 나열하는 매뉴얼이나 기존 고객용 CRM 업무 화면이 아닌, 제품 선택과 상담 진입을 돕는 공개 소개 페이지입니다. 제품별 바로가기 URL을 지원해 영업 상담 과정에서도 특정 제품부터 안내할 수 있습니다.

디자인은 더존 공식 홈페이지의 제품 중심 구성, 큰 타이포그래피와 여백을 참고합니다. 아이원소프트뱅크·AX/DX 로고와 제공받은 3D 에셋을 사용하며, 공식 사이트의 블루·시안과 Pretendard를 사용합니다. 애니메이션은 제품에 주목하게 하는 용도이고, 건너뛰기와 모션 줄이기 대안을 제공합니다. 제품 화면 소개는 한 화면 높이에서 기능을 전환하는 갤러리로 제공합니다.
