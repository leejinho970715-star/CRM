# 공개 배포 범위

이 저장소는 UI 시안과 가상 샘플 데이터만 포함합니다.

- 고객명: 샘플 고객사 01~10
- 고객 코드: DEMO001~010
- 사업자번호: 000-00-00001~00010 (실제 등록번호가 아닌 예시)
- 담당자/입력자: user_1~3; 사용자 표시: 사용자님
- 연락처 및 금액·일정·뉴스·기록: 생성한 시안 데이터
- 이메일/도메인: example.invalid
- 운영 사이트 원본 캡처·로그인 정보·원본 구조 수집 JSON·브라우저 저장소는 공개하지 않음

PNG·PDF·OG·ZIP은 새 샘플 데이터로 다시 생성했습니다. 공개 대상은 정적 HTML/CSS/JS, 문서, 브랜딩 에셋, 공식 OFL 글꼴, 생성한 시안 이미지와 패키지입니다.
